# 단어 한 장

영어Ⅱ 시험 대비용 공개 단어장입니다. 로그인 없이 암기 카드, 객관식 퀴즈, 오답 복습을 이용할 수 있습니다.

- 교과서 1과 48개, 3과 32개
- 모의고사 128개
- 수능특강 27개 지문 216개
- 합계 424개 출처별 항목 (같은 단어도 출처가 다르면 별도 항목)

단어의 뜻은 해당 지문의 문맥을 기준으로 정리했습니다. 빈칸 추론, 문맥 교정, 자료 누락은 메모로 표시했습니다. 교재 전체 지문은 포함하지 않고 짧은 학습 표현만 제공합니다.

학습 기록은 각자의 브라우저에만 저장되며 서버로 전송되지 않습니다. 다른 주소나 기기로 이전하면 이전 기록은 자동으로 옮겨지지 않습니다.

## 실행 및 배포

Node.js 22.13 이상에서 npm install 후 npm run build를 실행합니다. GitHub Pages 게시 위치는 main 브랜치의 /docs입니다. 정적 파일과 상대 경로를 사용하여 저장소 이름과 관계없이 실행됩니다.
